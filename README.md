# Simple Notes

シンプルに書いて、検索・タグ・アーカイブ・ToDoで整理できるブラウザ用メモアプリです。

公開URL: https://simple-notes-drab.vercel.app/

## 概要

Simple Notes は、Next.js、TypeScript、Tailwind CSSで作った学習用アプリです。
メモとToDoを画面上部から切り替え、それぞれを独立して整理できます。

同じタブで再読み込みした場合は、最後に開いていたメモ／ToDo画面と、選択中のToDoリストに戻ります。スマートフォンではToDoリストの詳細画面を開いていたかどうかも復元します。削除・アーカイブされたリストは開かず、利用可能なリストへ戻ります。選択中のメモは復元しません。

データはブラウザの `localStorage` に保存します。バックエンドやデータベースを使わず、フロントエンドの基本的な状態管理やデータ保存を学びやすい構成にしています。

## 主な機能

### メモ

- メモの作成、編集、削除
- リッチテキストエディタによる本文編集
- Markdownショートカットによる見出し、リスト、引用、コードブロックの作成
- タイトル、本文、タグを対象にした検索
- 複数タグの追加、削除、再利用、絞り込み
- ピン留め
- アーカイブと復元
- 複数メモの選択削除
- 更新日、作成日、タイトルによる並び替え
- メモ一覧の折りたたみ

### ToDo

- ToDoリストの作成、選択、確認付き削除
- リストごとのタスク追加、完了切り替え、個別・選択削除
- すべて完了、すべて未完了、完了済み削除の一括操作
- すべて、未完了、完了によるタスク絞り込み
- リスト名、タグ、タスク名を対象にした検索
- リストへの複数タグの追加、削除、再利用、絞り込み
- リストのピン留め
- リストのアーカイブと復元
- 複数リストの選択、アーカイブ、削除
- 更新日、作成日、タイトルによる並び替え
- リスト一覧の折りたたみ

### 共通

- メモ / ToDo の画面切り替え
- 同じタブでの再読み込み後も、最後に開いた画面を維持
- PC、スマートフォンに対応したレスポンシブUI
- スマートフォン用の展開式操作メニュー
- ライト、ダーク、端末設定に合わせるテーマ切り替え
- ユーザー名の変更
- `localStorage` による自動保存
- 開発者コマンドからの確認付き初期データリセット
- メモ・ToDo用のサンプルデータ追加

## 使い方

### メモを書く

1. 上部の切り替えで `メモ` を選択します。
2. サイドバーの `+ 新規メモ` からメモを作成します。
3. 編集エリアでタイトルと本文を入力します。
4. 上部のタグ欄から新しいタグや過去に使ったタグを追加できます。
5. 検索、タグフィルター、並び替えを使ってメモを整理します。

### ToDoを管理する

1. 上部の切り替えで `ToDo` を選択します。
2. サイドバーの `+ 新規リスト` からリストを作成します。
3. 選択したリストへタスクを追加します。
4. 完了したタスクにチェックを入れます。
5. リストにはタグ、ピン留め、アーカイブを設定できます。
6. チェックリストアイコンから、完了状態の一括変更や完了済みタスクの削除ができます。

PCでは一覧項目にカーソルを合わせると操作アイコンが表示されます。スマートフォンでは `…` ボタンから操作メニューを開きます。
### 設定と開発者コマンド

サイドバー下部の歯車ボタンから、ユーザー名とテーマを変更できます。
`開発者コマンド`では、サンプルデータやテストメモの追加、確認画面付きの初期データリセットを実行できます。

## Markdown入力

メモ本文では、編集とプレビューを分けずに書けるリッチテキストエディタを使っています。
行頭で次の記号を入力してスペースを押すと、対応するブロックへ変換されます。

````txt
#   見出し1
##  見出し2
### 見出し3
-   箇条書き
1.  番号付きリスト
>   引用
``` コードブロック
````

## 自動テスト

テスト実行には Node.js 24.12 以上の24系を推奨します。追加のテスト用パッケージは不要です。

```bash
npm test
```

メモ一覧15件、ToDoの追加・完了切り替え・削除6件、ToDoリストの選択復元4件、保存ガード12件、保存データの解析・保護25件（計62件）の単体テストを実行します。画面操作は対象外です。Node.js標準のテストランナーとTypeScript実行機能を使用します。型チェックは別途実行してください。

実行時に `MODULE_TYPELESS_PACKAGE_JSON` 警告が出る場合があります。既存プロジェクト全体のモジュール設定を変更しないため残しており、テストの失敗ではありません。

## 保存について

メモ、ToDoリスト、タスク、タグ、ユーザー名、テーマ設定はブラウザの `localStorage` に保存されます。同じブラウザであれば、ページを再読み込みしてもデータは残ります。

別の端末や別のブラウザとは同期されません。また、ブラウザのサイトデータを削除すると保存内容が消える可能性があります。

## 複数タブで開いたとき

別タブでメモ・ToDoが変更されると、そのデータの保存を停止し警告を表示します。未保存の文章は画面に残るので、必要な内容をコピーしてから「最新の内容を再読み込み」を押してください。確認を承諾すると、このタブの未保存の変更を破棄して最新の保存内容を読み込みます。

安全な保存にはWeb Locks対応ブラウザとHTTPS（ローカル開発ではlocalhost）が必要です。利用できない場合や保存処理に失敗した場合も保存を停止し、画面で通知します。更新前の旧版を開いたタブはこの保護に協調しないため、利用前にすべてのタブを再読み込みしてください。

`npm test`では検索等の15件、ToDo操作の6件、ToDoリストの選択復元4件、保存ガードの12件、保存データの解析・保護の25件（計62件）を確認します。競合の自動マージやバックアップ・復元機能はありません。

## 保存データを読み込めないとき

メモ・ToDoの保存データをすべて読み込めない場合は、該当する画面の編集と自動保存を停止し、元の保存文字列を保持します。一部のメモ・リスト・タスクだけ不正な場合も、残りだけを保存して元データを削ることはありません。正常な側のメモ／ToDoは引き続き利用できます。

再読み込みだけで直るとは限りません。復旧を相談する際も、ブラウザのサイトデータは削除しないでください。自動修復やデータの取り出し・復元機能は未実装です。古い形式の正常なデータは引き続き読み込みます。旧形式のToDoが0件の場合は、空のリストとして読み込みます。
